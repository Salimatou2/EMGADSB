# EMGADSB

 Application ASP.NET Core MVC pour la gestion d’un parc automobile.

---

## Description

EMGADSB est une application de gestion de voitures permettant d’afficher l'inventaire, de filtrer les véhicules par marque, prix, disponibilité, etc.  
L'application intègre un système d’authentification avec des rôles (Admin et User).

---

## Technologies utilisées

- ASP.NET Core MVC
- Entity Framework Core
- Identity (Authentification)
- SQL Server LocalDB
- Bootstrap

---

## Fonctionnalités

- Recherche et filtrage de voitures
- Affichage des marques et modèles
- Authentification avec rôles
- Zone d’administration (en cours)
- API pour récupérer les modèles selon la marque
